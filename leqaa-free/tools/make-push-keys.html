Make the phone notification keys

Open this file on your computer (double-click it). The keys are created inside your browser and are not sent anywhere.

1. Public key

Paste this into public/config.js as VAPID_PUBLIC_KEY, and also save it as the secret VAPID_PUBLIC_KEY in Supabase.

2. Private key

Secret. Save it only as the Supabase secret VAPID_PRIVATE_KEY. Never put it in config.js, never upload it with the website, never send it to anyone.
